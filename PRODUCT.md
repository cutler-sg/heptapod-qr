## Platform

## Stack
The brief requests a lightweight TypeScript/browser app with local bundled dependencies. Implementation choice: TypeScript, Bun tooling, a standalone built HTML file, no server or runtime network.
## Users and purpose
Michael and a tattoo artist compare circular organic black-ink designs based on exact spelling, an explicitly chosen phrase, or non-reversible decorative art.
## Confirmed constraints
The supplied specification governs: original Arrival-inspired fan encoding, never canonical translation. Preserve case, whitespace and Unicode unless explicit NFC is selected. No AI service, film assets, telemetry, accounts, transmission, publication or remote repository. Distinguish source geometry decoding from artist derivatives and metadata. Physical measures are design checks, never healing guarantees.
## Evidence
Audited heptapod-ink v1 restored commit, source and tests. Behind the Name supplies Michael's traditional etymology. No canonical Michael glyph or complete film-name grammar is verified.
## Assumptions
The initial design is a desktop workbench with a mobile stacked layout; this is an implementation assumption, not a stated user preference. Source/derivative comparison is central.
