# Changelog

## 0.1.0 — local release preparation

Initial Heptapod QR release preparation; no public release, remote or tag has been created.

- Offline, single-file text-to-logogram workbench with twelve reproducible seeded studies.
- Preserved heptapod-ink restored-v1 source encoding, separate artist vectors, strict source/project import and explicit input normalization.
- Physical screening, SVG/PNG exports, mirrored transfer, print sheet, project and provenance manifest.
- Offline example gallery and deterministic ZIP packaging with SHA-256 checksums.
- Compatibility, contribution, security-readiness and manual release documentation.

The photo comparison identified the `Who is like God?` source, seed 46, as the closest visual match. The separate optical experiment recovered no checksum-valid text and is not a supported scanner. Public product naming does not migrate existing saved-format or renderer identifiers.
