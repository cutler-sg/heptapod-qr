# Example studies

All artwork is original procedural Arrival-inspired fan work. Nothing is a verified alien translation or traced film glyph.

Each named folder includes twelve source/artist pairs (seeds 42–53), selected-seed source/stencil/reversed/explicit mirrored transfer SVGs, PNG, true-scale print HTML/PDF, project and manifest. The complete payload appears in project, manifest and comparison files. SVGs contain no plaintext metadata, but source geometry is reversible.

- `Michael/`: exact case-sensitive spelling.
- `michael/`: different exact lowercase spelling; never substituted silently.
- `who-is-like-god/`: explicitly selected traditional meaning phrase “Who is like God?” for the original name Michael.
- `there-is-no-linear-time/`: original encoding of English “There is no linear time”, not the film's glyph.
- `decorative-Michael.svg`: non-reversible hash-derived art, with its separate project.
- `comparison.html` / `.pdf`: exact spelling, chosen phrase and decoration with source/artist columns. These images are fitted for comparison, not print templates.

Use each `print-at-100-percent` sheet at 100%/Actual size, measure its 50 mm scale bar, and review `manifest.json` constraints plus `docs/ARTIST-CHECKLIST.md`. Warnings are preserved in the manifest; none are automatically corrected by discarding marks. Artist SVGs have no supported geometry decoder.
